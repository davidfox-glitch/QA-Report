# Project Overview

## What is QAFlow Pro?
QAFlow Pro is an Enterprise Testing Management Platform designed to streamline the Quality Assurance process. It serves as a central hub where QA engineers and project managers can track testing progress, document test cases, attach screenshots, leave notes, and monitor feature functionality in real-time.

## Main Purpose
The core purpose of QAFlow Pro is to replace scattered spreadsheets and disconnected tools with a unified, real-time dashboard. It provides immediate visibility into what is working, what is failing, and what needs to be tested, ensuring that software releases are stable and thoroughly vetted.

## Target Users
- **QA Engineers & Testers:** To execute test cases, log actual results, upload proof (screenshots), and track test status.
- **Project Managers & Admins:** To oversee project health, assign tasks, review analytics, manage user access, and generate reports.
- **Developers:** To receive clear, actionable feedback on failed test cases, complete with attachments and contextual notes.

## Business Goals
1.  **Accelerate Release Cycles:** Reduce time spent tracking down bugs and test statuses.
2.  **Improve Quality:** Ensure no test case slips through the cracks with structured lifecycle management.
3.  **Centralize Knowledge:** Keep all test artifacts (expected results, actual results, screenshots, discussions) in one place.
4.  **AI Integration:** Leverage AI to summarize testing progress and assist in note-taking and analysis.

## Current Progress
- **Core Infrastructure:** ~80% complete (Next.js SPA routing, Supabase Auth/DB, Zustand state management).
- **Task Management:** Complete (Active, Archive, Trash lifecycles established).
- **User Access:** Complete (Google OAuth, Role-based access control, Admin/User distinctions).
- **Notifications:** Complete (@mentions and activity logging).

## Future Vision
The future of QAFlow Pro involves deep AI integration. Beyond just summarizing data, the vision is to have AI automatically analyze uploaded screenshots to detect UI defects, predict testing bottlenecks based on historical data, and generate automated test scripts based on the "How to Test" descriptions. It will become a proactive testing assistant rather than just a reactive tracking tool.
